# 【核心任务目标：提取通用爬虫引擎模版参数】

我正在使用 Python Playwright 构建一个标准化的 AI 绘画平台自动化控制中心。我们有一套标准的引擎模版，现在需要你通过分析我提供的【多状态 DOM 时间轴】，帮我提取目标网站的“核心物理坐标（DOM选择器）”和“交互逻辑”，以填补我们模版中的空缺。

请仔细分析下方的 DOM 结构演进，并为我找出以下 5 大核心模块的最佳 Playwright 定位器和操作建议：

### 🎯 目标 1：环境初始化与清理 (Rebirth 阶段)
- **目标**：寻找“新建项目”、“新对话”或“清理当前画布”的按钮。
- **输出要求**：给我最稳定的 CSS 选择器。

### 🎯 目标 2：参数配置面板 (Config 阶段)
- **目标**：寻找切换到“图像/绘图模式”的按钮，以及“选择画幅比例（如 16:9, 9:16）”或“选择模型”的入口及选项按钮。
- **输出要求**：列出展开面板的按钮定位器，以及选中具体参数的定位器（如果有下拉菜单请说明层级）。

### 🎯 目标 3：垫图装载通道 (Upload 阶段)
- **目标**：寻找上传参考图的入口。
- **输出要求**：请告诉我它是【流派A：存在原生的 `<input type="file">` 标签，可以直接 `set_input_files`】，还是【流派B：必须点击某个 UI 按钮来触发系统的 file chooser】？并给出对应的选择器。

### 🎯 目标 4：火力输出控制 (Submit 阶段)
- **目标**：寻找填入提示词的输入框 (`textarea` 或 `input`)，以及触发生成的发送按钮 (`button`)。
- **输出要求**：给出这两个元素的精确选择器。并请注意观察发送按钮是否有 disabled 状态的 class 变化。

### 🎯 目标 5：战果收割与防伪 (Download 阶段)
- **目标**：寻找生成完毕后的真实图片元素，以及它的下载机制。
- **输出要求**：
  1. 怎么判断图片生成完毕了？（比如出现了某个特定的 class，或者去除了 loading 状态）。
  2. 它的下载方式是【流派A：直接提取 `<img>` 标签的高清 `src` 属性】，还是【流派B：网页上有一个真实的“下载”或“保存”按钮供点击】？请给出对应提取逻辑或按钮定位器。

---
**⚠️ 输出规范**：
请不要给我写一整套完整的 Python 爬虫脚本！我只需要你按模块列出提取到的 **常量名、CSS 选择器字符串** 和 **简短的交互逻辑说明**，以便我将它们填入现有的系统模版中。
